These are some of the ML models used to identify which features were more relevant in predicting CO performance (PSA; 2020). 

The company wanted a tool to improve the selection process for candidates who wanted to follow a career path on CO. The CO training was long (six months) and expensive so they had to make a careful selection of candidates who would be more like to succeed at the CO training.  
For this project I used the scores on behavioral and cognitive tasks to predict which candidates were more likely to succeed as CO. The best model was the Logistic Regression (a=.89). Through this model it was possible to substantially improve the selection process with an evidence-based tool combining psychological evaluation and data science. 
The pre-processing (cleaning, data exploration, feature selection and feature engineering) had already been performed with other tools.
